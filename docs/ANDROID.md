# ساخت APK

نسخه‌ی اولیه‌ی اندروید همان برنامه‌ی وب است که داخل یک پوسته‌ی Expo (WebView) اجرا می‌شود.

## راه ۱: GitHub Actions (بدون نصب چیزی روی کامپیوتر)
1. یک مخزن خصوصی در GitHub بسازید و همه‌ی فایل‌های این پوشه را در آن بریزید.
2. در تب Actions گزینه‌ی «Build Android APK» را اجرا کنید (Run workflow).
3. پس از پایان (حدود ۱۰ تا ۱۵ دقیقه)، فایل APK را از بخش Artifacts دانلود کنید و روی گوشی نصب کنید.
   (نصب از منبع ناشناس را باید در تنظیمات گوشی اجازه دهید.)

## راه ۲: روی کامپیوتر
نیازمند Node 20، JDK 17 و Android SDK:
```
npm install
npm test
npm run apk
```
فایل خروجی: `android/app/build/outputs/apk/release/app-release.apk`

## نکته‌ها
- این نسخه با کلید دیباگ امضا می‌شود؛ برای انتشار در فروشگاه باید کلید اختصاصی ساخته شود.
- فونت فارسی از اینترنت بارگیری می‌شود؛ بدون اینترنت فونت سیستم نمایش داده می‌شود (در مرحله‌ی بعد داخل برنامه قرار می‌گیرد).

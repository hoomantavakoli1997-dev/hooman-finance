# امضای اختصاصی APK دارا

## چرا لازم است
تا الان APK با «کلید debug» اندروید امضا می‌شود؛ این کلید برای همه شناخته‌شده است. یعنی هر کسی می‌تواند APKی بسازد که اندروید آن را «به‌روزرسانی معتبر دارا» بداند. علت هشدار Play Protect هم همین است. با یک کلید اختصاصی که فقط خودتان دارید، فقط نسخه‌هایی که شما بسازید روی دارا نصب می‌شوند.

## هشدار مهم
- فایل کلید را **هرگز** در مخزن نگذارید (مخزن عمومی است).
- اگر کلید یا رمزش گم شود، دیگر نمی‌شود به‌روزرسانی داد و همه باید برنامه را پاک و دوباره نصب کنند. از فایل کلید و رمزها در دو جای امن (مثلاً فلش و مدیر رمز) نسخه نگه دارید.
- بار اول که با کلید جدید نصب می‌شود، اندروید اجازه‌ی نصب روی نسخه‌ی قبلی را نمی‌دهد. پس هر کاربر باید: ۱) از تنظیمات برنامه پشتیبان بگیرد، ۲) دارا را پاک کند، ۳) نسخه‌ی جدید را نصب کند، ۴) از فایل پشتیبان بازیابی کند. بهتر است این کار را وقتی انجام دهید که هنوز کاربران کم هستند.

## مراحل
1. روی رایانه‌ی خودتان Java (JDK 17) را نصب کنید و در ترمینال بزنید:
   ```
   keytool -genkeypair -v -keystore dara-release.keystore -alias dara -keyalg RSA -keysize 2048 -validity 10000
   ```
   دو رمز می‌پرسد (رمز فایل و رمز کلید؛ می‌توانید هر دو یکی باشد). اسم و سازمان را هرچه خواستید بنویسید.
2. فایل `dara-release.keystore` و رمزها را در دو جای امن نگه دارید.
3. فایل را به متن تبدیل کنید:
   - ویندوز (PowerShell): `[Convert]::ToBase64String([IO.File]::ReadAllBytes("dara-release.keystore")) | Set-Clipboard`
   - مک/لینوکس: `base64 -w0 dara-release.keystore`
4. در GitHub: مخزن ← **Settings ← Secrets and variables ← Actions ← New repository secret** و این چهار مورد را بسازید:

   | نام | مقدار |
   |---|---|
   | `DARA_KEYSTORE_B64` | متنی که در مرحله‌ی ۳ کپی شد |
   | `DARA_KEYSTORE_PASSWORD` | رمز فایل |
   | `DARA_KEY_ALIAS` | `dara` |
   | `DARA_KEY_PASSWORD` | رمز کلید |
5. یک ساخت جدید اجرا کنید (Actions ← Build Dara Android APK ← Run workflow). اگر کلید درست تنظیم شده باشد، در گزارش ساخت پیام «release signing patched» می‌آید و دیگر هشدار «signed with the public Android debug key» نمی‌آید.

بدون این چهار مورد، ساخت مثل قبل با کلید debug کار می‌کند و چیزی خراب نمی‌شود.

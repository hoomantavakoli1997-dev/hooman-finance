# دارا | DARA

مدیریت دارایی‌ها و امور مالی شخصی؛ فارسی، راست‌چین و با تقویم شمسی.

## اصول محصول
- سادگی و خوانایی؛ حفظ مسیرهای آشنای برنامه
- حفظ اطلاعات قبلی هنگام ارتقا و مهاجرت
- محاسبات مالی دقیق و بدون حدس‌زدن قیمت‌های ناموجود
- هویت بصری سرمه‌ای و فیروزه‌ای با تأکیدهای طلایی ملایم

## ساختار
- `src/core/`: منطق مالی، قیمت‌ها، اشخاص، اقساط، یادآورها، قفل و پشتیبان رمزدار به‌همراه تست‌ها
- `web/`: رابط فارسی و ساخت خروجی وب و HTML مخصوص WebView
- `App.tsx`: پوسته اندروید (Expo)، اعلان‌ها، دریافت قیمت و نصب به‌روزرسانی
- `docs/ARCHITECTURE.md`: معماری و تصمیم‌های فنی

## اجرا و آزمون
```
npm install
npm test
npm run web:build
```

## نگهداری اطلاعات
- نسخه فعلی، دفتر اطلاعات را در فضای ذخیره‌سازی WebView نگه می‌دارد.
- فایل پشتیبان با PBKDF2-SHA256 و AES-256-GCM رمزنگاری می‌شود.
- قفل برنامه از هش رمز استفاده می‌کند، اما به‌تنهایی رمزنگاری داده‌های ذخیره‌شده نیست.
- انتقال به SQLite و رمزنگاری داده‌های محلی باید همراه با مهاجرت قابل‌بازگشت و آزمون بازیابی انجام شود؛ تا پیش از آن، پشتیبان‌گیری پیش از ارتقا ضروری است.

## قیمت‌ها
- TGJU و TSETMC از طریق لایه‌های جداگانه دریافت قیمت استفاده می‌شوند.
- قیمت‌های نامعتبر، صفر، جهشی یا کهنه باید رد شوند.
- قیمت آزمایشی یا داده‌ی نمونه نباید به‌عنوان قیمت قطعی نمایش داده شود.
